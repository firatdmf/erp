{% load i18n static %} {% comment %} What crm/js/record_detail.js needs from the server, then the script itself. The three CRM record pages — contact, company, supplier — include this once, at the end of their content, so they run the same code and say the same things. Expects: kind ("contact" / "company" / "supplier"), record, notes_partial_url. Optional: record_name — passing it sends "Task" in the attach menu to the sidebar task form with this record already picked (a task can be attached to a contact or a company, not a supplier); emails_url, shared_files_url — the Communication tab; edit_name, edit_url — "Contact" / "Company": the edit sidebar whose handlers the script provides. {% endcomment %}
