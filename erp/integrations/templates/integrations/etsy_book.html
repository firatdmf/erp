{% trans "How it works" %}

{% trans "What it reads." %} {% trans "The shop's orders, Etsy's fees and the payouts Etsy sends to the bank. Nothing more: it never changes anything on Etsy — no listings, no stock, no messages to buyers." %}

{% trans "Etsy is a customer." %} {% trans "Buyers pay Etsy, and Etsy owes the money to this book until it pays out. So everything is recorded on Etsy's account, chosen on the right:" %}

  • {% trans "Each Etsy order becomes an order to Etsy from the chosen warehouse, at the price without tax — Etsy collects sales tax and pays it on itself. As with any order, the sale is recorded when the order is completed." %}
  • {% trans "Each Etsy fee is an expense in the chosen category, paid by Etsy's account." %}
  • {% trans "Each deposit to the bank is a dividend to the chosen person, paid by Etsy's account." %}

{% trans "Etsy's account therefore shows what Etsy holds for this book. It differs from Etsy's own balance only by the Etsy orders not completed here yet." %}

{% trans "Buyers' privacy." %} {% trans "Etsy's rules allow keeping only what the books need: an order keeps the buyer's name and the Etsy order number. No address, no customer record and no emails to buyers." %}

{% trans "Right now: preview only." %} {% trans "The preview shows, for the days you choose, what would be recorded — it writes nothing. Until then, record Etsy sales, fees and payouts by hand on Etsy's account, the same way." %}
